# 3D Canvas native-first capability boundary — 2026-10-23

## Binding DM decision (not an art or playability acceptance)
Do **not** reproduce functionality already supplied by installed 3D Canvas, 3D Canvas Premium, Mapmaking Pack, Token Collection or core Foundry V14. Before writing custom gameplay/camera/collision/vision/cutscene/editor code, inspect the actual installed runtime, source and official docs; identify the native UI, registered setting, existing API, license and plugin combination that supplies it; test that path in a disposable QA scene. Our bridge may automate **native API calls**, capture/validate inputs and verify results; only add genuinely absent functionality after a reproducible deficiency is established. No vendor source edits, no invented visible geometry, no world-wide Falling/settings changes to mask failures, no unapproved source art modifications.

## Reuse-first validation gates (required before custom implementation)
1. Classify requested feature: base Foundry, installed 3D Canvas, Mapmaking Pack/Premium or genuinely absent.
2. Read installed matching source and version-specific official docs; inspect the exact runtime registration/setting and whether the UI is currently instantiated. Check licensing before reuse; Mapmaking Pack **Token Collection** assets cannot simply be redistributed into other runtimes.
3. Test native UI action or native API in isolated GM-only QA clone at **renderer ready**, with before/after values, actual player/GM roles and rollback. For vision test actual player viewpoint, not just GM; for movement use real drag/interaction, not TokenDocument teleport; for Camera test Game Camera and free first-person separately.
4. If native path works, expose the smallest guarded bridge adapter only if hands-free automation actually needs it. Extend MCP wrapper schema instead of reimplementing 3D Canvas mechanisms.
5. If native path fails, log exact reproducible deficiency/versions/settings; distinguish vendor limitation, disabled setting, broken import metadata, or out-of-band Foundry D&D5e integration. Repair at the responsible layer; no vendor patch or extra visible mesh without express authorization.
6. Preserve accepted Scene/Blender source, disposable test IDs and exact revision checks. Disabled global Falling is **not** evidence that ground support works.
