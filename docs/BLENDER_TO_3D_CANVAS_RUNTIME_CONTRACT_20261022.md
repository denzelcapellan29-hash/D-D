## 8. 60-foot radial darkvision scale gate — confirmed 2026-10-22
DM explicitly called out that darkvision is radial, not 60/4 by compass direction. Official Foundry Token Vision Angle defaults to 360° and Token Vision Range is a Scene-distance value, while the source D&D5e actor records a physical range (e.g. 60 feet). Camera FOV is a separate rendering control; never equate the two or divide the radius among compass points. Current Area8 QA Monk actor darkvision=60 ft, Token `sight.range=60`, `angle=120`; Foundry Scene is gridless with `grid.size=100`, `grid.distance=1`, `grid.units=""`. Installed Area8 Blender-to-Foundry world scaling is 75 pixels per source metre. Therefore **60 physical ft = 18.288m = 1371.6px = 13.716 Area8 Scene distance units**. Existing `sight.range=60` instead corresponds to **6000px = ~262.47 physical feet**, but the room's invisible 800px-radius wall ring and the 120° cone can make actual visible distances much shorter. The QA Druid token's nearest point on that ring is ~18.45ft away; this can visually resemble a ~15ft limit. This is NOT a four-direction rules division. In a measured 5ft/100px grid the token would instead need `sight.range=12`, but Area8 uses a different source-derived physical scale. Do not change Area8's grid distance or camera rig just to make a token number look like 60. Calibrate vision from each authored world's metre/pixel scale, then assign 360° token sight for the rules baseline, preserving a 120° cinematic mode as separately tagged OPTIONAL only.
