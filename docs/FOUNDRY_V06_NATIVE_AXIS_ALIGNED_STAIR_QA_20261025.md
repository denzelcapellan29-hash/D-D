## Critical SOURCE discovery: native keyboard orientation
READ installed `levels-3d-preview/scripts/wrappers.js` only. Native wrapper for `TokenLayer.prototype.moveMany` calls `handleArrowKeys`, which rotates the requested cardinal input by **camera yaw** before movement/collision. It obtains candidate ground elevation from vertical geometry movement ray, then horizontally blocks when BVH collision occurs. Therefore a `dx=0,dy=-1` button under default diagonal GM camera does NOT mean north/world negative-Y movement.
