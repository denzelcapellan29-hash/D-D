## Fast room lane, stages T0–T6
- **T0 source**: open official map/text once for each room revision; source-tag topology, dimensions, doors, elevation, sight lines, encounter keys, secrets. Never assume a room template is automatically source-faithful.
- **T1 asset registry**: choose a verified, visually coherent native Tile/Prop family, measure real collider and rotational placement semantics in the installed TaleSpire `Taleweaver/<pack>/index.json`; only approved source Meshy assets may be used for signature hero moments; reject missing UUIDs, unregistered architectural meshes or mismatched connectors.
- **T2 semantic->slab**: canonical horizontal metric pitch 1.524m; source-aligned grid positions and quarter-height integers, 90° native Tile yaw, 15° native Prop yaw; generate deterministic room placements from room topology/templates; lint occupancy, deliberate wall-to-floor bearings, exits, supports, roof, path widths. AABB checks are conservative metadata, NOT proof of mesh connection. Emit Slab v2 only with actually registered UUIDs; batch paste rather than click-per-tile.
- **T3 runtime**: disposable board only; record source hash, catalog hash, tool version, generated slab hash and number of placements. Paste once into game with a captured rendered preview, click to commit once, ESC cancel duplicate ghost, render structural/hero camera screenshots and inspect actual floor/wall joins. Do not trust web screenshot or one black camera angle; no camera trick hides errors.
- **T4 gameplay**: place and move one native test miniature across the walking surface, verify entrance and secret handling with GM rules; require persistence by board reload. DM explicitly waived multiplayer testing (2 in-person players). HDMI GM/player display test postponed, **not accepted**.
- **T5 signature asset**: for approved original Meshy hero, use hash-addressed independent Blender background derivative; performance budget per role, exact bottom-center anchor correction AFTER decimation/topology; tri mesh and UV/material preserved; albedo, normal, MAOS PBR packed channels; independently reimport FBX and compare at least source/derivative matching front/side PNGs. Official TaleWeaver Lite supports **creatures only**, max 60,000 vertices; never claim creature behaves as structural Tile/Prop; local `.tsMod` creation needs Unity Hub, Unity 2021.3.45f2 Personal account/license, actual UI compilation, followed by LocalContentPacks test and in-game visual/spawn/movement evidence. No Meshy provider charge unless required confirmation received.
- **T6 release**: differentiate LINT PASS / NATIVE IMPORT PASS / RENDER PASS / NAVIGATION PASS / PERSISTENCE PASS / DM ART ACCEPTED. Unverified gates remain labeled. Store canonical blueprint, slab, asset registry, source/costs and actual screenshots; update CURRENT_HANDOFF compactly with *one* latest checkpoint and a link to an immutable dated QA report; do not copy full history into every handoff/doc.
