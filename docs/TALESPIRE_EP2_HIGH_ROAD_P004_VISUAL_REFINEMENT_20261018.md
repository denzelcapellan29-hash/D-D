## Lessons for repeatable efficient production
- Test road surface palette and tree assembly in actual TaleSpire preview **before committing** an entire room. Preview-only P003 was rejected in minutes; P002 remains untouched.
- For modular forest/swamp vegetation, a native `base + mid + leafy top` family is a complete tree; combining only base and top leaves an implausible stump. Record Y anchors and visually inspect joins rather than assuming collider AABB means a true connector.
- Not all things named `Road` look like a muddy travel road; check the actual rendered material and avoid alternating high-frequency color-band tiles over long distances.
- Soften wetland tile grid boundaries with sparse vegetation and naturally interrupted patches rather than a checkerboard of grass/swamp modules. Current effect is an improvement, not nature-mimicking perfect continuity.
- Maintain immutable old scene revisions, a single semantic plan, native registry validation, actual PNG structural/hero review, one-paste staging, backend reload and timing labels for real efficiency benchmarks.
